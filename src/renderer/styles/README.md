# styles — Tema e estilos

Carregados por `<link>` no `index.html` (ver o motivo no README do renderer).

- `tema.css` — variáveis de cor, espaçamento e fonte (`:root`), foco visível e `.sr-only`
- `layout.css` — menu lateral, área de conteúdo e cabeçalho das telas
- `componentes.css` — botões, tabela, campos, abas, modal, toast, etiquetas e estados

Cores com contraste mínimo de 4,5:1; status e alertas sempre com texto além da cor.

**Responsável:** Pessoa 4
